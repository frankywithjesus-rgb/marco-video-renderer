# assets/escuela-sabatica

Sube aquí las imágenes de cada episodio (referencia de Sami + fondos de escena, ya compuestos juntos).

## Convención de nombres
`ep{numero}-escena{numero}.png`

Ejemplos para el episodio piloto (Lección 7 - "Un retrato del amor", episodio 1):
- ep1-escena1.png
- ep1-escena2.png
- ep1-escena3.png
- ep1-escena4.png
- ep1-escena5.png

## Cómo subir
1. Entra a este folder en GitHub (botón "Add file" → "Upload files").
2. Arrastra las imágenes PNG/JPG generadas.
3. Cada imagen queda pública automáticamente en:
   `https://raw.githubusercontent.com/frankywithjesus-rgb/marco-video-renderer/main/assets/escuela-sabatica/NOMBRE.png`
4. Copia esa URL en el campo "image" del JSON de escenas del formulario n8n.
